# Applied Machine Learning Portfolio

A visual course portfolio by **Xinyue Wang**, built as a static site for GitHub Pages.

## Artifacts

| # | Title | What it demonstrates |
| --- | --- | --- |
| 01 | [Algorithm Atlas](artifacts/01-algorithm-atlas/) | Visual taxonomy of 12 ML methods, domains, and use cases. |
| 02 | [Inside a Neural Network](artifacts/02-neural-network-visual-guide/) | Nine-slide interactive presentation on layers, neurons, weights, activations, loss, optimizers, and the training loop. |

The second artifact has interactive inputs for weighted sums, activation functions, squared error, and a single illustrative gradient-descent update. It also includes a [downloadable PowerPoint](artifacts/02-neural-network-visual-guide/Neural_Network_Components.pptx) and an exploration plan for [TensorFlow Playground](https://playground.tensorflow.org/).

**Educational scope:** The interactive numeric examples demonstrate calculations; they are not results of a trained machine-learning model or a benchmark. The Playground experiments listed in Artifact 02 are suggested comparisons, not reported experimental measurements.

## Local use

Open `index.html` in a browser. For the embedded website presentation, open `artifacts/02-neural-network-visual-guide/index.html`.

## Publish with GitHub Pages

Repository Settings → Pages → Deploy from a branch → `main` / `(root)`.

This is an **incremental update** to an existing repository. When applying its ZIP distribution, preserve the existing `assets/` folder and `artifacts/01-algorithm-atlas/` folder.
