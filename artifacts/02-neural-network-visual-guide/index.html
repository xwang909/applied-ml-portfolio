05 / IMPROVEMENT

Optimization turns feedback into updates.

Gradients estimate how the loss changes with each parameter. An optimizer uses them to update the parameters.

COMMON OPTIMIZERS
Gradient Descent

Uses an aggregated gradient to update parameters.

Stochastic Gradient Descent (SGD)

Updates from individual or mini-batch examples; mini-batch SGD is common.

Adam

Adapts parameter-specific step sizes using estimates of gradient moments.

06 / HOW THE PIECES FIT

Learning is a repeatable loop.

Layers, neurons, weights, activation, loss, and optimization each play a different role.

01

Inputs move through layers, weighted sums, and nonlinear activations.

02

03

Backpropagate

Use the chain rule to compute parameter gradients of the loss.

∂L/∂w
04

Update parameters

An optimizer changes the weights and biases; the cycle repeats.

w ← w − η∇L
The distinction: a loss function scores the mistake; backpropagation computes gradients; an optimizer updates the parameters.
